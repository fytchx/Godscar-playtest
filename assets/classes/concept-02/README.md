**Asset status:** SOURCE_CREATED / visual review pending
**Source:** owner-selected Concept 2 rune/sigil emblem artwork, from the November 2026 Godscar class symbol exploration.
**UI boundary:** The current Fight/Character mock, simulation and all deployed websites stay unchanged.

## Exported files
- Six independent SVG class emblems: GS-CLS-ICO-001 through GS-CLS-ICO-006, with dark interior/gold compass-point medallions and class-accent glyphs.
- Six separate glyph-only SVGs for reuse in Skills, UI headers and small buttons.
- One separate SVG neutral gold medallion frame. Every assembled emblem remains independently usable.
- All use an editable 128x128 SVG viewBox, transparent exterior, no labels or bitmap images, no external dependencies. Source is under `assets/classes/concept-02/svg/`.
- Any raster PNGs or review screenshots belong in the downloadable review ZIP, not this source directory.

## Glyph identities
Paladin: gold cross/star of radiance. Warrior: three-pronged ember battle rune. Rogue: lilac crescent/blade stroke. Mage: ice-blue arcane compass star. Archer: green precision arrow / bow mark. Shaman: seafoam threefold elemental spiral.

Class colors are visual identity accents only. They do not approve class-restricted weapon rules or overwrite damage-source colors. Class automatic abilities continue to come exclusively from the equipped main-hand weapon.

Check each glyph at 24, 36, 48 and 64 CSS px, particularly the warrior/archer shapes and Shaman spiral. Use the class-frame SVG or the assembled emblem SVG; labels belong in HTML/CSS, not the art source.
