# Godscar gilded chrome Batch 2 / 4

35 independent SVG frames for primary and secondary button states, pill controls, icon button shells, dropdowns, tab choices, and footer navigation treatments. CSS and HTML own text and interaction; the SVGs are their own vector edge sources. Gold and deep teal-black surfaces match Batch 1. Selected-state green is a deliberately modest interaction accent, not a replacement for damage-source or rarity semantics.

For non-square controls use nine-slice border-image with slice about 22px. Hover/pressed/disabled are separate files; do not paint all states onto one bitmap. Source/status/use catalog is at assets/ui/gilded-chrome/v1/catalog/batch-02.json. Visual concept boards not traced. No icons, game art, or mechanics.
